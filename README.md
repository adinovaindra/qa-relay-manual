# Relay — End-to-End Manual QA

## Project Overview

This repository contains a self-directed QA portfolio project for **Relay**, a full-stack 1-on-1 messaging application.

The project demonstrates an end-to-end manual QA workflow, from requirement analysis and risk assessment through test design, execution, defect reporting, retesting, regression testing, and test summary.

## System Under Test

**Application:** Relay  
**Testing Type:** Manual QA  
**Project Type:** Self-directed QA portfolio project

## QA Scope

The testing scope will cover the core Relay functionality, including:

- Authentication
- Authorization
- 1-on-1 conversations
- Messaging
- Message persistence
- Conversation list behavior
- UI states
- Theme behavior
- Responsive behavior
- Message history behavior

Detailed scope, requirements, risks, test cases, execution results, and defects are documented in the project artifacts.
